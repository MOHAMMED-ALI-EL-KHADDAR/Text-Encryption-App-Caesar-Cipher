Functions:
  - main() - CLI entry point with argparse

Algorithm:
  - Encryption: (char_index + shift) mod 26
  - Decryption: (char_index - shift) mod 26
  - Brute-force: Try all 26 shifts, return all results

================================================================================

Weakness Analysis:
  ✓ Only 26 possible keys
  ✓ Vulnerable to brute-force (milliseconds)
  ✓ Vulnerable to frequency analysis (seconds)
  ✓ Vulnerable to known-plaintext (instant)
  ✓ Deterministic (same input = same output)
  ✓ No authentication or integrity checking
  ✓ Character distribution preserved

Comparison to Modern Encryption:
  Caesar Cipher:    26 keys, breakable instantly
  AES-256:          2^256 keys, unbreakable with current tech
  Key Space Ratio:  1 : 10^77 (AES is incomparably stronger)
